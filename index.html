一次完整使用长这样示例为模拟演示

1
你 · 开始页
「我想利用晚上时间摆个摊赚点钱，但完全不知道卖什么……」
2
成事工坊 Skill · 讨论区
先问最影响判断的三件事：最多能亏多少、一周能出摊几晚、地铁口已有几个同类摊。你逐条回答。
3
Skill 给出计划草案 → 你在网页点「确认」
验证什么（地铁口有效时段的真实需求）、具体动作（周五六晚蹲点数人流+问两个摊主）、做到算完、投入上限、该停就停的条件。确认后工作台直接生成任务，零复制。
4
你 · 现实中行动，回到同一事项记下结果
「晚 7-9 点约 300 人经过，烤肠摊一晚净赚约 120-180」——证据（摊主原话、计数表照片）和执行记录存在同一个地方。做小生意小试时，验证单自动算利润/时间/现金三笔账。
5
你点「带着结果继续讨论」→ Skill 读取全部记录复盘
对照事前定的判断条件给建议：哪些假设被支持、下一步做什么、什么时候该停。想暂停或终止，任何阶段都能记录理由。

成套安装并开始

装好后，日常动作只有一个：打开「成事工坊」→ 开始或继续一件事。

支持条件

Windows（首发实测环境） 已安装并登录 Claude Code 讨论走你已登录的 AI 账户计费

安装入口（真实制品）

  1. 获取本仓库代码（git clone https://github.com/xiaoxiaosml-star/idea-to-done.git 或下载 ZIP 解压）。
  2. 双击运行 installer/install.cmd。安装器自动检测环境、注册并安装插件、准备数据目录、创建启动入口，无需手动装依赖、写路径或开终端。
  3. 从开始菜单或桌面的「成事工坊」启动，它会自动拉起本地服务并打开工作台。

macOS / Linux 打包已预留，未在对应系统实测前不宣称支持。更新只需重跑安装器，不清空你的项目数据；安装与服务日志在数据目录的 install.log，启动报"服务未能确认"时按提示手动结束残留 node 进程后重试即可，数据不会丢失。

你的数据在哪

项目记录只存在你的电脑本机（独立数据目录，与插件缓存分开）。讨论时，必要的上下文会发送给你正在使用的 AI 服务——这一点如实说明：本工具不建云账户、不收数据，但「AI 讨论」这一步走的是你自己的 AI 软件账户与计费。
