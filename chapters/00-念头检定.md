# 第零步：念头检定

> **什么时候回到本章**：脑子里冒出新念头的时候——不止创业念头，备考、转行、学技能、减肥、搬家，任何"我想做个什么事"都算。念头不检定就立项，是浪费精力的头号来源；这一步就是"不凭空捏造"的闸门。

## 三问定生死（写下来再答，别想完就算）

**① 这算不算一件事？**

一句话说清你要做成什么，然后补一句"怎么算做成了"——**验收标准**。

写不出来验收标准，**不是你不合格，多半是还没见过这事真做成的人**——预期不是想出来的，是探出来的。这种情况别硬写，先去探路：

- 看一个真实案例（真人在做的，不是短视频里演的）
- 问一个做过的人，要一个真实数字
- 查一份真实报价或行情

拿到参照物再回来补标准。**探路本身是正经工序**：探完发现这事根本不存在，也是一次成功的排除。

三种标准别混在一起，要求的松紧不一样：

| 标准 | 示例 | 要求 |
|---|---|---|
| 行动完成标准 | 今天找到 3 个真实店铺案例 | 必须有，做完没做完一眼能查 |
| 信息获取标准 | 搞清楚开店有哪些费用，列出已知项和未知项 | 可以边做边明确 |
| 商业结果标准 | 三个月净赚 3000 元 | 不必一开始就有，探路回来再补 |

- 不合格例："我想搞点副业"（什么标准都没有）
- 合格例："三个月内，副业月净收入达到 1000 元"

**② 最坏结果我承受得起吗？**

把最坏的结局具体化：亏多少钱、花多少时间、会不会影响主业/学业、家人知道了会怎样。每个都写出具体答案，不许写"应该没事"。

- 答得出具体数字，还要再过两问：这笔钱/时间花出去，基本生活受不受影响？有没有不可逆的后果（健康、信用、关系）？都过了 → 承受得起，继续
- 答不出、或一写具体就怕 → 先不动，回第三编的方法把投入上限砍到承受得起为止，或者干脆放下这个念头——**放下不合适的念头也是成事**

**③ 值得试一次吗？**

问自己：做成了，生活具体哪里变好？说不出具体的改变（不是"会更好"，是"每月多 1000，房租就不紧了"），先别急着定性——可能是这念头是别人塞给你的，也可能是你连这事长什么样都还没见过（回第一问去探路）。分辨方法：探完路还无感，才是别人的愿望；别人的愿望成不了你的事。

> 例外：只是好奇想了解、不投钱不投时间？那不用过三问，直接去探路——三问是"要投入之前"的闸门，不是"想了解"的闸门。

## 判定

三问全过 → 念头升级为"项目"，进第一编。
任何一问卡住 → 卡住的那问就是下一步要解决的问题，解决前不做任何投入。

> 本步你拿走的：念头三问（是不是事 / 亏不亏得起 / 值不值得试）——每个念头三十秒过一遍闸门，过不去的省下的是真金白银
