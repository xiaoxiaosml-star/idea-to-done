# 第三编：目标怎么明确

> **什么时候回到本章**：换方案的时候、摊子变大的时候、定价或成本变了的时候、每月复盘的时候——任何数字一变，目标就要重新拆、三笔账就要重新算。这张表是你经营过程的仪表盘，不是立项时的一次性作业。

> 目标不是喊出来的数字，是一套拆解的本事。方法就一句话：**把大目标拆到拆不动为止，给每个小目标配一个解决方案；方案没用，就换方案，直到问题解决。**

## 核心方法：拆 → 解 → 换

1. **拆**：大目标 → 子目标 → 小目标 → 拆到"无法再往小拆"的原子动作
2. **解**：每个原子目标，配一个解决方案（怎么做、找谁、花多少）
3. **换**：方案执行了没用 → **不换目标，换方案**；直到问题解决

## 示范：一个目标是怎么被拆穿的

目标：**摆摊第一个月赚 3000**。

- 第一层拆：3000 ÷ 30 天 = 每天 100 元
- 第二层拆：每天 100 元 = 卖出多少件？→ 先算**每件扣掉变动成本后剩多少**：进价 10 元、卖 30 元，包装损耗摊每件 3 元 → **剩 17 元**（注意：固定费用还没扣，别叫它"净利"）——每天需要约 6 单（不是 5 单）
- 第三层拆：6 单/天从哪来？→ 客流量 × 成交率。假设成交率 20%，需要 30 个有效顾客/天
- 拆到不能拆：30 个顾客从哪来？→ **这就是最底层的小目标**

给它配解决方案：

| 小目标 | 方案 A | 没用就换 |
|---|---|---|
| 每天 30 个有效顾客 | 摊位选在 XX 路口（早高峰人流） | 换位置（晚市/学校门口） |
| 顾客停下来看 | 样品摆前排+明码标价 | 换陈列/换展示方式 |
| 看了愿意买 | 定价 15 元起，首单优惠 | 换价格带/换品类 |
| 买完还再来 | 留联系方式，下次减 2 元 | 换话术/换复购品 |

**算"赚"之前，先算三笔账**（漏一笔，目标就白定）：

| 账目 | 回答的问题 | 上面例子的数字 |
|---|---|---|
| 收支与利润 | 扣完所有费用，卖一单净剩多少？一个月净剩多少？ | 单件毛利 17 元（扣变动成本后，固定费用还没算）；每天还有摊位费/交通约 30 元固定费用 → 每天净利 ≈ 17×6-30 ≈ 72 元，月净利约 2100 元——**不是 3000** |
| 现金占用 | 先付款后进账，中间要垫多少？ | 首批进货 50 件 × 10 元 = 500 元押在货上，回款前要吃饭 |
| 时间投入 | 获客、守摊、售后一共几小时？ | 每天 5 小时 → 时薪约 14 元，跟自己打零工比一比 |

看到了吗：**大目标落地后，你的待办清单里没有一个词超过 10 个字；账算全之后，目标数字本身可能都要改**。到这一步，目标才算定完——之前都只是愿望。

## 空白模板（抄下来填你的）

**第一步：拆**

| 层 | 填什么 | 你的答案 |
|---|---|---|
| 大目标 | 一句话，带数字和时间（例：第一个月净赚 X 元） | |
| 每天/每周要多少 | 大目标 ÷ 天数 | |
| 每单/每件剩多少 | 售价 − 每件变动成本 | |
| 每天要几单 | 每天要的钱 ÷ 每件剩的 | |
| 几单从哪来 | 客流 × 成交率 → 需要多少有效顾客 | |
| 最底层小目标 | 拆到不能拆的那个动作 | |

**第二步：解**（最底层小目标后面，每个配方案 A 和"没用就换"）

| 最底层小目标 | 方案 A（怎么做/找谁/花多少） | 没用就换 |
|---|---|---|
| | | |

**第三步：算三笔账**

| 账目 | 填什么 | 你的数字 |
|---|---|---|
| 利润账 | 月营业额 − 已售商品成本 − 所有其他费用 | |
| 现金占用 | 进货要先付多少 + 回款周期几天 | |
| 时间账 | 每周总投入几小时 ÷ 净利 = 时薪 | |

三笔账常见漏项（填完对着查一遍）：

- 利润账：摊位费/平台扣点/包装/交通/损耗——**只算了进货价是最常见的错**
- 现金占用：货押的钱、押金的钱、"先干活后结账"的应收账款
- 时间账：守摊/客服/售后/来回路上的时间——只算"制作时间"会严重高估时薪

## 换方案的三条纪律

1. **投入有上限**：动手前先定好"这个方案最多投入多少钱、多少时间"，到上限就停下来复核结果——不为"试满几天"硬撑，把弹药耗在一个无效动作上
2. **一次只换一个变量**：位置和定价同时换，你永远不知道是哪个起的作用
3. **记录再换**：把"方案 A 做了什么、结果是什么"写下来再换 B。不复盘的迭代只是乱撞

## 目标本身什么时候可以改

验证够久之后（比如 1~2 个月），满足**全部三条**，可以改目标：

- 底层小目标配过 ≥3 个不同方案，结果都不行
- 每次都有书面记录，不是"感觉不行"
- 改动写成一句话结论存档（例："XX 路口早市客流不足，换三个位置均无效，该品类放弃"）

**可以改目标 ≠ 随时改目标**：拆开不到两周、只试过一个方案就说"目标定错了"，那是用"改目标"给"没执行"打掩护。目标改动的真正价值是那行存档的结论——它比"做成了"值钱，因为它替你排除了一条路。

## 完成标志

你的目标变成了一张表：每个原子动作后面跟着一个正在执行的方案，和"没用就换"的备选。
