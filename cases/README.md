# 案例库（建设中）

**真实案例的完整复盘**——这是本站最值钱的部分：不晒成功，只拆过程。

## 每个案例的统一拆解维度

- 起步时兜里有多少钱、每周多少小时
- 第一个动作是什么、什么时候做的
- 第一笔钱怎么来的（金额、来源、花了多久）
- 踩过的坑（至少写一个真金白银的）
- 现在的状态（做了多久、月流水量级、还在不在做）
- 如果重来一次，会改哪一件事

## 收录标准

- 必须是真实经历（投稿需同意公开，可匿名）
- 不收录"月入十万"式爽文，只收录过程可追溯的
- 失败的案例和成功的同等欢迎——失败复盘对新手价值更大
- **没有真实成交记录的数字演示，一律标注"演算示例"**（示例见 [案例演算示例_摆摊首月.md](案例演算示例_摆摊首月.md)）

> 建设中——欢迎开 issue 投稿
