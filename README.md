# 成事方法论（Idea to Done）

**轻资产创业，低成本成事。**

**从一个念头，到一件事做成。每一步都写成能照做的动作。**

## 这个项目是什么

一套**成事方法论开源库**：把"我想做件事"变成"做成了"，中间每一步——心动、选择、拆解、动手、迭代、撑住——都拆成行为级的动作、模板和清单。

考研上岸、找工作、做副业、摆摊、学技能、减肥搬家——**大事小事都算成事**。轻创业是最典型的一条主线，但方法本身不限于此：凡是"从念头到做成"的事，都用得上。

市面上讲"成事"的内容，要么是演讲腔的成功学，要么是引流卖课的广告，真正落到实处的经验全被捂着卖钱。这里反着来：**全部开源、全部免费，能写多细写多细，持续完善。**

> 这套方法不承诺带你走到终点。它承诺的是：这段路每个人都得走，走几遍因人而异——**路是绕不开的，趟法是可以学的**。

## 写给谁

- 有想法、但总卡在"不知道第一步干什么"的人
- 没什么家庭支持的毕业生、初入社会的年轻人
- 能接受从小做起、慢慢验证、把失败变成排除记录的人

## 不做什么

- **不替任何人做决定**——做不做、选哪个、投多少，是你的事，这里只提醒该干什么、看什么、防什么
- **不承诺结果**——只提供方法、模板和核对清单，没有"保证成功"这种话
- **零商业元素**——无课程推广、无引流话术、无联系方式

## 内容状态说明

当前为 V0.4：五编一步已细化到**行为级**——每条方法都能回答"下一步做哪个动作、做到什么程度算完、什么结果该停"，并附带可照抄的空白模板和勾选清单（各编开头标注"什么时候回到本章"，各编末尾标注修订日期）。深潜层《从一个念头到一门生意》V1.3 为全流程模拟验证版，其中所有数字均为模拟值，不构成市场结论。案例库含 1 个明确标注的"演算示例"，真实案例持续收稿中。涉及政策、费用的内容均以官方最新公告为准。

## 使用方式

- **直接读**：`chapters/` 下的方法 + `cases/` 的案例
- **动手时**：打开 [首次小生意验证单](tools/首次小生意验证单.html)——动手前写四行字，结束后算三笔账（纯前端，数据只在你本地浏览器；在线版：https://xiaoxiaosml-star.github.io/idea-to-done/tools/首次小生意验证单.html ）
- **对话式带路**（进阶，需要 Claude Code / Cursor 等 AI agent）：先把**整个仓库**克隆到本地，再在 agent 技能目录软链 `skills/idea-to-done/`（安装步骤见该目录下 SKILL.md）。**只复制 skills 文件夹不带仓库，正文不会跟过去**
