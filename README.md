# 成事工坊（Idea to Done）

**轻资产创业，低成本成事。**

**从一个念头，到一件事做成。每一步都写成能照做的动作。**

## 这是个什么地方

**成事工坊不是资料库，是干活的地方。** 资料只让人"读过"，工具只让人"用过"，这里把两者钉在一起：一道工序 = 一段方法（图纸）+ 一件工具（扳手）。你每来一次，就完成一个小小的环节，留下一个产出和下一步的依据。全部工序走完，结局如实确认：达成、继续验证、暂停，或理性终止——后三种同样算成事。

工坊里装着一套**《成事方法论》**：把"我想做件事"变成"做成了"，中间每一步——心动、选择、拆解、动手、迭代、撑住——都拆成行为级的动作、模板和清单。

考研上岸、找工作、做副业、摆摊、学技能、减肥搬家——**大事小事都算成事**。轻创业是最典型的一条主线，但方法本身不限于此：凡是"从念头到做成"的事，都用得上。

市面上讲"成事"的内容，要么是演讲腔的成功学，要么是引流卖课的广告，真正落到实处的经验全被捂着卖钱。这里反着来：**全部开源、全部免费，能写多细写多细，持续完善。**

> 这套方法不承诺带你走到终点。它承诺的是：这段路每个人都得走，走几遍因人而异——**路是绕不开的，趟法是可以学的**。

## 写给谁

- 有想法、但总卡在"不知道第一步干什么"的人
- 没什么家庭支持的毕业生、初入社会的年轻人
- 能接受从小做起、慢慢验证、把失败变成排除记录的人

> 当前版本工具与案例以轻创业为主线；备考、转行、减肥搬家等场景的**方法本身通用**（第零步+五编都适用），专用工具与案例在持续补齐。

## 不做什么

- **不替任何人做决定**——做不做、选哪个、投多少，是你的事，这里只提醒该干什么、看什么、防什么
- **不承诺结果**——只提供方法、模板和核对清单，没有"保证成功"这种话
- **零商业元素**——无课程推广、无引流话术、无联系方式

## 使用方式

三种用法，数据和存储各是各的，**互不自动同步**：

- **直接读**：`chapters/` 下的方法 + `cases/` 的案例，浏览器或任意编辑器打开即读。
- **独立工具（免 AI，纯浏览器）**：打开 [成事工序台](tools/成事工序台.html)——点"你现在是什么状态"进对应工位，填任务卡、排进今天、做完回收证据；或打开 [首次小生意验证单](tools/首次小生意验证单.html)——动手前写四行字，结束后算三笔账。数据只存在本机浏览器 localStorage，不建账户不上传；**导出/导入 JSON 可整体备份还原，误删先进回收站（30 天内可恢复）**；"最有效一招"会收进你的心法库供下次复用。换电脑/清浏览器前记得导出。在线版：https://xiaoxiaosml-star.github.io/idea-to-done/tools/成事工序台.html
- **对话式带路（推荐，需要 Claude Code）**：获取本仓库代码（`git clone https://github.com/xiaoxiaosml-star/idea-to-done.git` 或下载 ZIP 解压）后，**双击运行 `installer/install.cmd`**——安装器自动检测环境、注册并安装插件、准备数据目录、创建「成事工坊」启动入口。之后**双击桌面的「成事工坊」**（或安装目录下的「成事工坊.cmd」）启动，它会自动拉起本地服务并打开工作台。支持条件：Windows（首发实测环境）+ 已安装并登录的 Claude Code；讨论走你已登录的 AI 账户计费。

### 更新、数据与故障

- **更新**：安装器只刷新插件注册与组件、不会自行下载新版代码——更新需先获取新版代码/ZIP 解压，再运行**新版目录**的 `installer/install.cmd`，沿用原数据目录即可，**项目数据保留**。
- **数据位置（AI 工作台版）**：项目记录只存在你电脑本机的独立数据目录（默认 `~/.chengshi-workshop`，可用 `CHENGSHI_DATA` 环境变量换位置），与插件缓存分开；每个项目是一个明文 JSON，**备份=整个复制该目录，恢复=把副本放回原位置**（服务停止时操作）。回收站、JSON 导出、心法库是独立工具版的能力，AI 工作台版没有，也不互相同步。讨论时必要的上下文会发送给你正在使用的 AI 服务——本工具不建云账户、不收数据，但「AI 讨论」这一步走你自己的 AI 软件账户与计费。
- **故障排查**：`install.log` 是**安装日志**（在数据目录下）；服务运行时输出不写入该文件，运行故障请记录屏幕/网页上的报错提示，连同安装日志一起反馈。启动入口报"服务未能确认"时，只处理**能确认属于成事工坊**的残留服务（报错信息里会给出依据）；无法确认归属时不要动其他 node 进程，把报错信息原样保留反馈即可，数据不会丢失。
