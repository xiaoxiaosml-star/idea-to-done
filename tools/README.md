# 工具箱

## 成事工序台（v0.3）

六关流水线工作台：入口自诊（没概念/模糊愿望/已卡住）→ 工位图纸 → 三行任务卡（动作/算完/该停）→ 排进今天/明天/本周 → 做完回收证据 → 结局如实记录（🎯 达成 / 🚀 继续 / 🛑 理性终止 / 🌫 还在探索）。

纯前端单机，**免 AI**，数据只存浏览器 localStorage。自带：全部事项**导出/导入 JSON**（换电脑或清浏览器前用它备份）、**回收站**（误删 30 天内可恢复）、"最有效一招"自动收进心法库供下次复用。这些能力是独立工具版的，AI 工作台版没有，两边数据也**不自动同步**。

注意：**"还在探索"是一种认知状态的记录，不等于"暂停"**——暂停是把行动停下来的决定，两件工具对"暂停"另有记录方式，不要把它们混用。

打开方式：双击 `成事工序台.html` 或访问在线版 `https://xiaoxiaosml-star.github.io/idea-to-done/tools/成事工序台.html`

首版先做**一个**工具，把价值落在一个真实场景上：帮用户完成并复盘一次小试。

| 工具 | 干什么用 | 状态 |
|---|---|---|
| [首次小生意验证单](首次小生意验证单.html) | 按第四编的"四行字"格式，记录一次试验的：验证什么、最多投入、支持继续的信号、停止条件；试验后填结果和三笔账（利润、现金占用、时间投入）；可保存（本地浏览器）和导出 Markdown | ✅ 已上线 |

**暂缓开发的**（没有足够依据前不生成分数或"适合你"的结论）：

- 起步自测器（自驱评分）——评分依据不足，先用第一编的三问自查
- 方向自动推荐——不如第二编的四问核实靠谱

> 每个工具都是纯前端、免安装、点开就能跑；数据只存在你自己的浏览器里。
