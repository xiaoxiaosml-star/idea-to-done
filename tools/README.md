# 工具箱

首版只做**一个**工具，把价值落在一个真实场景上：帮用户完成并复盘一次小试。

| 工具 | 干什么用 | 状态 |
|---|---|---|
| [首次小生意验证单](首次小生意验证单.html) | 按第四编的"四行字"格式，记录一次试验的：验证什么、最多投入、支持继续的信号、停止条件；试验后填结果和三笔账（利润、现金占用、时间投入）；可保存（本地浏览器）和导出 Markdown | ✅ 已上线 |

**暂缓开发的**（没有足够依据前不生成分数或"适合你"的结论）：

- 起步自测器（自驱评分）——评分依据不足，先用第一编的三问自查
- 方向自动推荐——不如第二编的四问核实靠谱

> 每个工具都是纯前端、免安装、点开就能跑；数据只存在你自己的浏览器里。
