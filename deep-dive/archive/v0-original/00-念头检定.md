# 第零步：念头检定

> **什么时候回到本章**：脑子里冒出新念头的时候——不止创业念头，备考、转行、学技能、减肥、搬家，任何"我想做个什么事"都算。念头不检定就立项，是浪费精力的头号来源；这一步就是"不凭空捏造"的闸门。

## 三问定生死（写下来再答，别想完就算）

**① 这算不算一件事？**

一句话说清你要做成什么，然后补一句"怎么算做成了"——**验收标准**。说不出来，它就不是一件事，是一个愿望。愿望留着无妨，但它没资格进后面五编。

- 不合格例："我想搞点副业"（没有验收标准）
- 合格例："三个月内，副业月净收入达到 1000 元"

**② 最坏结果我承受得起吗？**

把最坏的结局具体化：亏多少钱、花多少时间、会不会影响主业/学业、家人知道了会怎样。每个都写出具体答案，不许写"应该没事"。

- 答得出具体数字 → 承受得起，继续
- 答不出、或一写具体就怕 → 先不动，回第三编的方法把投入上限砍到承受得起为止，或者干脆放下这个念头——**放下不合适的念头也是成事**

**③ 值得试一次吗？**

问自己：做成了，生活具体哪里变好？说不出具体的改变（不是"会更好"，是"每月多 1000，房租就不紧了"），说明这个念头是别人塞给你的，不是你真要的——别人的愿望成不了你的事。

## 判定

三问全过 → 念头升级为"项目"，进第一编。
任何一问卡住 → 卡住的那问就是下一步要解决的问题，解决前不做任何投入。

> 本步你拿走的：念头三问（是不是事 / 亏不亏得起 / 值不值得试）——每个念头三十秒过一遍闸门，过不去的省下的是真金白银
