# 从一个念头到一门生意

一个面向普通人的、可执行、可验证、持续迭代的开源创业手册。

> **来源与许可**：本手册源自《成事方法论》（Idea to Done）V0.2 的行为级骨架（`archive/v0-original/` 为原始六篇稿件），扩写为 19 章全流程深潜版。全项目内容遵循 CC BY 4.0：可自由共享演绎，需署名《成事方法论》并注明修改。
>
> **验证状态**：V1.3 的全部验证为合成案例 + 结构压力测试，**所有数字均为模拟值，未经真实项目验证**。它是一套"待下水的完整结构"，不是市场结论。

## 这不是一本成功学

它试图记录一件事情怎样从“不存在”变成“存在”：

**念头 → 问题 → 用户 → 需求 → 方案 → 交易 → 交付 → 经营 → 系统 → 增长。**

## 当前版本

**V1.3：非线性现实乱序压力测试版。**

00—18 主流程、两套贯穿系统、配套工具已经齐全，并已使用一个完整合成创业案例从 00 跑到 18，修复第一轮执行断层。

## 从哪里开始

第一次使用：从 `handbook/00-念头检定.md` 开始。

每一章都不是“读完算完成”，而是必须达到章节末尾的通关条件。

工具在 `tools/`。

## 重要声明

本项目仍处于实践验证期。通用结构已经建立，但行业数据、阈值、法律税务与具体市场判断不能靠手册替代真实调查和专业意见。

遇到真实项目与手册冲突时：

> **先尊重事实，再修改手册。**
