# 工具｜00 念头检定卡

> 用途：任何“我想做……”的念头，在正式投入之前先填一次。
>
> 这张卡不判断项目一定能不能成功，只决定：**它值不值得获得一次小成本验证的机会。**
>
> 建议复制后另存为：`YYYY-MM-DD-念头名称.md`

---

# 基本信息

**念头名称：**

**日期：**

**这个念头最初是怎么出现的？**

> 例如：自己遇到问题 / 看到别人做 / 朋友推荐 / 工作中发现 / 突然想到 / 其他

---


# 前置分流｜这件事需要进入创业流程吗？

这次念头是否包含以下目标：

> **探索它能否创造对外价值，并通过交易形成收入或持续经营。**

- [ ] 是 → 继续填写本卡
- [ ] 否 → 它可以是很好的个人目标，但无需强行进入完整创业流程

---

# 第一问｜我到底想验证什么？

不要写：

> 我想创业。  
> 我想搞副业。  
> 我想做自媒体。

改成：

> **我想验证：________________________________________。**

辅助问题：

- 大概是谁？
- 他可能有什么问题 / 需求？
- 我真正想从现实里知道什么答案？

**我的答案：**

> 我想验证：

# 第二问｜如果它成立，我为什么想做？

可以非常现实，不需要写使命。

例如：

- 每月增加 X 元收入；
- 验证一项技能能不能赚钱；
- 为未来转行准备；
- 建立长期事业；
- 对这个问题非常感兴趣；
- 手里有资源，想验证是否能转化；
- 即使不赚钱，这次探索本身也能让我得到重要答案。

### 金钱停止线

> 累计投入达到 __________，不再自动追加。

### 证据停止线

> 如果出现 ______________________________________________，重新检查问题 / 用户 / 方向。

### 风险停止线

> 如果发现 ______________________________________________，直接停止本轮探索。

# 最坏情况检查

如果这一轮探索失败：

**最多损失多少钱？**

> 

**最多损失多少时间？**

> 

**会不会影响主业 / 学业 / 家庭基本生活？**

> 

**有没有不可逆后果？**

> 

**这个最坏结果我承受得起吗？**

- [ ] 承受得起
- [ ] 承受不起
- [ ] 目前还不知道

如果选择“承受不起”或“不知道”：

> **先降低验证成本或查清风险，不进入下一关。**
