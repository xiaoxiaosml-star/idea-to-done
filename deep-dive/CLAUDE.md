# CLAUDE.md

## 项目定位
这是《从一个念头到一门生意》开源创业手册。当前 V1.3。

## 优先级
1. `项目总纲_V0.1.md`：项目最初总纲与原则。
2. `README.md`：当前版本状态。
3. `handbook/`：00—18 正文。
4. `tools/`：配套工具。
5. `systems/`：贯穿系统。
6. `research/tests/`：结构压力测试与修订依据。
7. `archive/`：旧稿，只用于追溯，不作为当前规范。

## 修改规则
- 不为显得专业而堆术语。
- 不把作者判断伪装成事实。
- 不把“朋友说不错”当需求验证。
- 每章必须有：核心问题、操作方法、常见错误或边界、通关条件、下一步。
- 重大结构调整先说明理由，再修改。
- 真实项目与手册冲突时，优先保留事实并提出修订。
- 需要行业阈值、法律税务、市场数据时标注待研究，不编数字。
- 保留 Git 历史，不覆盖旧版本的演化证据。
- 与门面层（仓库根 `chapters/`）重叠的概念（三笔账、四行字、目标拆解、漏斗排查等），以门面层为锚：本层只做展开、不重新定义；同一条改动涉及两层时，先改门面层再同步本层，防止两套说法漂移。

## 当前下一任务
V1.3 已完成非线性现实乱序压力测试（24 个情境 + 经营路由器 + 风险门）。**不要继续凭空扩章节、不要继续加工具。**

下一阶段（唯一优先级）：
1. 选择一个真实创业项目进入 `cases/ongoing/`；
2. 从 00 开始实际填写工具；
3. 区分【真实数据】、【当事人判断】、【推测】；
4. 任何真实结果与手册冲突时，记录冲突并提出修订；
5. 未经现实验证，不把模拟案例数字当行业基准。

## V1.3 非线性路由规则
- 00—18是教学主干，不是现实经营强制顺序。
- 经营中先读 `tools/00A-经营状态路由器.md`。

- 多项目用 `00C-项目组合决策表.md`。
