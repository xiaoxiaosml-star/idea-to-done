# 12｜经营漏斗：不要说“生意不好”，指出到底哪一环坏了

> 核心问题：从陌生人第一次看见你，到复购和推荐，损失发生在哪里？
>
> **什么时候回到本章**：想说"生意不好"的时候、想加码投流的时候、纠结先改哪的时候——先回这一章把"不好"翻译成具体哪一环坏了。

## 基础漏斗

**曝光 → 兴趣 → 询问 → 成交 → 交付 → 满意 → 复购 → 推荐**

不同业务可以增删，但必须让“生意不好”变成具体可诊断的问题。

## 每一环只问两个问题

- 有多少人进入？
- 有多少人进入下一环？

再结合定性原因。

## 例子

（以下为演示用假设数字，不是行业基准。）

1000 人看到，100 人停留，20 人询问，2 人购买。

此时不要先优化复购。最大问题可能在询问到成交。

如果 20 人购买、15 人投诉，则优先修交付，继续拉流量只会放大伤害。

## 瓶颈原则

一次优先修最影响整体结果的一环。

不要因为“内容比较好改”就永远只改内容。

## 不只有转化瓶颈

经营至少检查三类瓶颈：

1. **转化瓶颈**：人进来了，但大量流失；
2. **产能瓶颈**：有人买，但交付能力跟不上；
3. **现金瓶颈**：业务看似增长，但现金先被库存、账期或扩张吃掉。

最大瓶颈不一定出现在漏斗百分比最低的地方，而是当前最限制整体继续增长的地方。

## 销售漏斗之外还有生命周期
订阅/课程/社群/软件增加：成交 → 激活 → 使用 → 价值实现 → 留存 → 续费/复购 → 推荐。内容业务区分受众指标、线索指标、交易指标和留存指标。流量好看不能替代商业结果。

## 增长质量
订单、流量、营业额上涨时，同时看退款、投诉、负贡献、延期和容量。增长让这些快速恶化时先停止加速。**爆单也可能是危机。**
